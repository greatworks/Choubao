# 《你个臭宝》关卡生成算法说明

> 用途：记录当前上线版本的关卡生成规则、难度指标和调参入口。
> 基准版本：2026-08-08。

## 1. 总体结构

游戏共 1000 关：

- 第 1 关是固定编排的 8 箭教学关，倒计时 180 秒。
- 第 2-1000 关使用确定性“轮廓蒙版 + 逆向路径抽取 + 依赖图求解 + 离线配方筛选”。
- `src/level-retries.js` 固化 999 关的种子、方向翻转、标准解和难度分析，运行时不做暴力搜索。

核心文件：

- `src/level-generator.js`：路径生成、依赖图、求解、分析与验证。
- `src/theme-catalog.js`：轮廓模板和确定性变体。
- `src/level-retries.js`：第 2-1000 关的已审核配方。
- `scripts/curate-levels.js`：离线筛选脚本。
- `tests/run-tests.js`：1000 关及完整功能回归测试。

## 2. 不变量

每根箭头的 `cells` 按尾部到头部保存，相邻单元格曼哈顿距离必须为 1。最后两个单元格决定箭头朝向。

正式关卡必须同时满足：

1. 路径连续、互不重叠、不能越出轮廓。
2. 箭头头部朝向与路径末段一致。
3. 头部正前方射线不能命中自己的箭身。
4. 开局至少有一根可消除箭头。
5. 依赖图无环，标准解能够清空全部箭头。

第 3 条由 `pathPointsIntoOwnBody()` 在生成、方向翻转和最终验证三个阶段共同保证。

## 3. 网格与视觉规模

第 2-1000 关固定使用：

```text
网格：51 行 x 34 列，共 1734 格
轮廓面积：至少占网格 70%
轮廓内路径覆盖率：至少 80%
正式箭头数：80-95 根
生成目标：90-95 根
```

轮廓来自 24 种动物、植物和生活物品模板，再通过镜像、旋转、缩放、位移和边缘扰动生成 999 个不同签名。

棋盘线宽由单元格尺寸动态计算：

```text
stroke = clamp(cellSize x 0.24, 2.2px, 5.2px)
```

缩小默认线宽只改变视觉密度，不扩大隐藏点击区域；玩家仍可双指缩放后精确点击。

## 4. 路径生成

生成器从完整轮廓反向抽取路径：

1. 找到当前剩余区域中可作为箭头头部的边缘单元格。
2. 优先选择会被已抽取箭头阻挡的候选，形成先后依赖。
3. 从头部反向生长正交折线路径，并禁止进入头部正前方射线，避免指向自身。
4. 路径延伸偏好短直行和频繁转弯，避免大段平行直线。
5. 抽取后吸收可连接的剩余单元格，并在不破坏可解性的前提下分割过长路径。
6. 使用邻接图着色，让相邻箭头尽量不同色。

长箭头判定阈值为 30 格；转弯不少于 4 次计为弯曲箭头。

## 5. 依赖图求解

对每根箭头，从头部沿朝向扫描到棋盘边界，射线上出现的其他箭头都是它的依赖项。

- 依赖数为 0：当前可消除。
- 消除一根箭头后：其所有依赖者的计数减 1。
- 所有箭头都能按拓扑顺序移除：关卡可解。
- 拓扑排序无法覆盖全部箭头：存在循环依赖，候选淘汰。

求解器在多个可消除候选中优先选择下一步前沿更小、且不会形成连续同方向操作的箭头。

## 6. 正式关难度门槛

第 2-1000 关全部使用同一套硬指标：

| 指标 | 门槛 |
| --- | ---: |
| 箭头总数 | 80-95 根 |
| 初始可消除数 | 1-4 根 |
| 平均可消除前沿 | 不超过 6 |
| 最大可消除前沿 | 不超过 9 |
| 长箭头 | 8-10 根 |
| 弯曲箭头 | 至少 18 根 |
| 每个方向最少数量 | 12 根 |
| 单方向最大占比 | 35% |
| 标准解连续同方向 | 不超过 3 根 |
| 近邻同轴同向违规 | 最多 1 处 |
| 倒计时 | 300 秒逐步降至 240 秒 |
| 点错扣时 | 10 秒 |

“近邻同轴同向违规”指同一行或列中，至少 3 个同向箭头头部连续靠近，且相邻头部间距不超过 3 格。相距很远的同向箭头不会形成视觉顺扫，因此不计为同一违规簇。

倒计时公式：

```text
P = clamp((level - 2) / 998, 0, 1)
timeLimit = 300 - floor(60 x P)
```

## 7. 教学关

教学关包含 8 根箭头：

1. 第一根是 4 格右向直箭，头部贴右边界，直接出界。
2. 第二根是 6 格上向直箭，头部贴上边界，直接出界。
3. 第三步引入长弯箭沿自身路线滑出的动画。
4. 后续引入真实阻挡和连续消除。

前两根明确朝向棋盘外，所有 8 根箭头都通过“头部不指向自身”验证。

## 8. 近失败与复活

难度主要来自收紧可消除前沿、方向混排和 10 秒点错扣时，而不是隐藏规则或扩大点击热区。

- 倒计时结束且剩余不多时，复活按钮显示“看视频复活，就差 N 根”。
- 时间耗尽时，激励视频复活增加 60 秒。
- 箭头移除动画允许并行，玩家不必等待上一根完全飞出即可继续点击。

这样可以形成自然的“差一点”局面，同时保持规则一致和操作可预期。

## 9. 离线筛选

筛选命令：

```powershell
node scripts\curate-levels.js
```

也可以按区间或指定关卡执行：

```powershell
$env:START_LEVEL='201'; $env:END_LEVEL='300'; node scripts\curate-levels.js
$env:LEVELS='150'; $env:MAX_RETRY='360'; node scripts\curate-levels.js
```

每个合格配方保存：

- `retry`：确定性随机种子序号。
- `flips`：需要反转头尾方向的箭头 ID。
- `solution`：标准可解顺序。
- `analysis`：上线难度指标快照。

本版本第 2-1000 关共 999 个配方均已通过严格门槛；最大离线重试为 178。

## 10. 调参建议

提高逻辑难度时，按以下顺序调整：

1. 降低初始可消除数。
2. 降低平均和最大可消除前沿。
3. 降低连续同方向和近邻同轴违规。
4. 调整方向占比。
5. 最后再缩短倒计时或提高点错扣时。

提高视觉复杂度时，优先调整网格、箭头数、轮廓面积和路径覆盖率。提高消除爽感时，优先调整长箭头长度、弯曲箭头数量和并行动画速度。

修改路径算法、网格、箭头目标或难度门槛后，必须重新筛选全部 999 个正式关卡。

## 11. 验证

```powershell
node --check src\level-generator.js
node tests\run-tests.js
```

完整测试必须确认：

- 1000 关全部可解。
- 999 个正式关全部满足上述硬指标。
- 没有箭头指向自己的箭身。
- 相邻关卡不复用相同轮廓签名。
- 教学、缩放、快速连续点击、并行动画、计时扣罚、复活和既有社交功能没有回归。
