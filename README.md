# 你个臭宝 - 微信小游戏

“你个臭宝”是一款竖屏蛇形箭头消除游戏。每根箭头由一条连续的正交折线和明确的方向尖组成：头部朝向前方没有其他箭头时，整根箭头像贪吃蛇一样沿自身路径移动并退出棋盘；前方被遮挡时会试探、碰撞并回到原位。

项目使用微信小游戏原生 Canvas 2D，零 npm 运行依赖，可直接导入微信开发者工具。

视觉采用明亮的 3D 卡通风格：主页使用“臭宝”角色徽章与立体品牌牌，关卡内使用高光 HUD、立体棋盘包边和材质化道具台；棋盘路径为高对比、无阴影的纯折线箭头，箭身采用紧凑细线，箭头尖单独放大以强化方向识别。

## 当前版本

- 第 1 关由 8 根纯折线箭头组成小型教学迷宫。前两根分别朝右、朝上紧贴棋盘边界，点击后直接出界；随后引导玩家识别长弯箭和阻挡关系，所有箭头都不会指向自己的箭身。
- 第 2-1000 关使用 51×34 网格的主题轮廓迷宫。24 种动物、植物和生活物品外轮廓经镜像、位移、缩放、旋转和边缘变体确定性组合，999 个密集关的图形签名全部不同；轮廓至少覆盖棋盘 70%，轮廓内路径覆盖率不低于 80%。
- 每根折线箭头保持单一颜色，相邻箭头通过邻接图着色自动避开同色；关闭“彩色”设置后统一显示为深色箭头。棋盘不使用常驻阴影，只有提示和碰撞时出现短暂高亮。
- 每个密集关包含 80-95 根真实可点击箭头，其中目标生成量为 90-95 根；包含 8-10 根长度不小于 30 格的长蛇和至少 18 根多转折长蛇。四个出口方向都至少出现 12 根，最大单方向占比不超过 35%，开局可消除入口为 1-4 根。
- 关卡从主题轮廓蒙版按真实解法顺序逐根抽取箭头，再经过依赖图评分、固定配方选择和自动求解器复核，保证可解且避免连续同向消除。
- 成功点击后目标会立即从碰撞占位中释放；上一队仍在爬行退场时，玩家已可点击新解锁队列，支持多队并行移动与快速连消。
- 支持双指捏合缩放、单指拖动画布、按钮缩放，缩放范围为 0.9-3.2 倍。
- 点错时箭头沿自身朝向向前试探后回弹，扣除 1 颗心和 10 秒；阻挡箭头同步闪红。
- 第 1 关保留原有奶声童音“臭宝”和快速连消“宝字音阶”；第 2 关起每关对应 1 首公版经典旋律，首根成功消除仍播放“臭宝”，后续严格按“一根箭一个音符”顺序演奏模拟钢琴音。每关顶部固定提示“这是什么歌？”，并以小字提醒“速度越快，旋律越清晰”。旋律在比原始转写高一个八度加纯五度的明亮音区播放，并使用更响亮的卡通钢琴击键；快速连点通过有限节拍排队保留乐曲节奏。10 首曲目按关卡循环，单关曲谱走完后也会从头循环。
- 全流程播放为本游戏程序化原创的无歌词卡通器乐：104 BPM、24 小节 A/A′/B 结构，玩具木琴、软弹贝斯、轻拨弦与低存在感打击乐组成约 55 秒循环；首页、关卡、弹窗和语音期间使用不同混音音量，并提供独立音乐开关。
- 通关触发臭宝角色弹出、旋转光束、彩纸、星芒、品牌语音和胜利和弦；结算页可生成 500×400 动态分享卡，把真实关卡缩略图、用时、连击和“臭宝”风格标签带入好友同图挑战。
- 首页提供“今日迷宫”和“好友榜”。好友从分享卡进入后挑战完全相同的确定性关卡；新玩家会先完成第 1 关热身，再无缝进入好友原局。失败时可分享当前残局，接收者从相同剩余箭头状态接手。
- 全流程使用统一的“臭宝”关系型文案：通关负责夸奖与点名挑战，失败负责安抚与残局求助，好友回流负责反超与回敬；分享标题、卡片短钩子及行动提示按真实局面生成，并通过 `copyId` 统计转化。
- 分享、好友挑战、今日迷宫均不作为领取主线奖励或继续游戏的条件；好友挑战不修改主线关卡进度。
- 广告采用克制策略，只保留玩家主动触发的复活和道具激励视频，不在开局、正常游玩或通关时强制弹出。
- 游戏不设体力门槛；金币继续通过通关累计，但当前版本没有金币消费入口。
- 擦除、魔法棒、提示、网格线各有 1 次初始额度。每种道具首次用完后可分享同图挑战领取 1 次补给；此后点击空额度道具会直接播放激励视频，完整观看后将 1 次额度存入账号，玩家再次点击才会使用。
- 日常操作统一使用直接状态反馈：道具选中、额度变化、提示高亮、网格开关、点错扣心和分享成功不再重复弹出渐隐文字；仅在隐私授权、平台能力或激励视频确实失败且界面无法解释原因时显示简短提示。
- 网格线在当前关卡只消耗 1 次额度，解锁后可反复开关；进入下一关后重置本关权限。

## 核心规则

箭头的 `cells` 按“尾部到头部”保存，相邻格子的曼哈顿距离必须为 1。最后两格确定箭头方向。

1. 点击后，从箭头头部沿最终方向扫描至棋盘边界。
2. 射线上没有其他活动箭头时，箭头进入 `escape` 状态。
3. 头部沿出口方向前进，身体沿原折线路径依次跟随，尾部逐格收缩。
4. 射线被挡时，箭头回弹并触发失败反馈。
5. 清空所有箭头后通关。

自身蛇身不构成阻挡。擦除和魔法棒属于强制道具，使用溶解动画移除目标。

## 导入运行

1. 打开微信开发者工具，选择“小游戏”。
2. 导入目录 `D:\WSCodex\IAAMiniArrowAndArrow`。
3. 核对 [project.config.json](D:/WSCodex/IAAMiniArrowAndArrow/project.config.json) 中的 `appid` 与发布后台一致。
4. 点击“编译”。

小游戏主包没有 npm 运行依赖。云函数依赖已锁定在 `cloudfunctions/social/package-lock.json`，部署时需选择“上传并部署：云端安装依赖”。

## 自动验收

```powershell
node tests\run-tests.js
```

测试会遍历全部 1000 关，并检查：

- 路径连续、无重叠、方向正确且不越界。
- 第 1 关为 8 根箭头的小型教学迷宫：首根仅 4 格、朝右直接出界，第二根朝上直接出界；两者向前射线均不与自身相交，后续逐步引入长弯箭和阻挡关系。
- 第 2-1000 关保持轮廓内 80% 以上路径覆盖，每关包含 80-95 根箭头、8-10 根长度不小于 30 格的长蛇和至少 18 根多转折长蛇。
- 999 个密集关的轮廓签名全部不同，并全部使用连续折线箭身与单一方向尖。
- 关卡箭头使用圆角细线、清晰三角箭头尖和相邻异色规则，不使用常驻阴影。
- 上一队移动未完成时，下一队可立即开始移动。
- 四向箭头数量、最大方向占比、连续同向长度、开局安全入口和局部同向行列都满足难度门槛。
- 开局既有安全箭头，也存在真实阻挡关系。
- 自动求解器能清空全部箭头。
- 同一关卡编号生成结果完全一致。
- 点错扣心、受阻回弹、合法消除、蛇形退出和双指缩放状态正确。
- Canvas 界面和所有主要弹窗可正常渲染。

当前验收结果：`All tests passed: 1000 levels`。

## 上线配置

在 [src/config.js](D:/WSCodex/IAAMiniArrowAndArrow/src/config.js) 中填写微信后台创建的广告位：

```js
var AD_UNITS = {
  rewarded: '激励视频广告位 ID',
  interstitial: '插屏广告位 ID',
  banner: 'Banner 广告位 ID'
};
```

广告位为空时，只有浏览器本地预览会直接返回奖励；微信环境不会在广告不可用时发放道具或复活。正式发布前还需要在微信公众平台完成小游戏资料、隐私保护指引、用户协议、防沉迷配置、分享素材和真机广告测试。

隐私能力采用“本地玩法优先”的门禁：启动和本地关卡不主动申请隐私授权；玩家首次使用好友榜、排行榜提醒、激励广告等联网能力前，才调用微信官方隐私授权弹窗。拒绝后仍可完整游玩本地关卡，且不会进入对应功能；再次点击相关入口会重新发起授权，直到同意后才继续。设置弹窗底部保留低权重的“隐私保护指引”文字入口，直接调用 `wx.openPrivacyContract` 查看微信平台登记版本。后台需先完成并审核通过“用户隐私保护指引”，声明好友榜使用的“微信朋友关系”，以及云挑战涉及的用户标识、关卡进度、挑战成绩和使用记录，再开启官方“隐私授权弹窗”。

好友挑战链接无需后端即可运行；挑战回流次数、好友尝试数和云端残局补全依赖微信云开发。发布前需确认 `SOCIAL.cloudEnvId`、集合 `choubao_challenges` 的客户端禁读写权限，并以云端安装依赖方式部署 `cloudfunctions/social`。详细步骤见 [SOCIAL_GROWTH.md](D:/WSCodex/IAAMiniArrowAndArrow/docs/SOCIAL_GROWTH.md)。隐私接口实现参考微信小游戏[隐私保护指引](https://developers.weixin.qq.com/minigame/dev/guide/open-ability/privacy.html)。

## 原创与合规

项目参考的是“蛇形箭头消除”玩法类型和用户提供的竞品截图，没有复制竞品代码、图片、音频或具体关卡数据。所有关卡均由本项目算法确定性生成，界面、图标和动画由 Canvas 原生绘制。正式上线前仍需完成名称、商标、美术素材和玩法表达的法务审核。
